# Continental Firearms

Launch website for Continental Firearms, a Carlisle Capital LLC venture.
Modern Engineering. American Heritage. Every Era.

Single page static site: `index.html` plus `assets/` (logo, intro music, images).
No build step. Open `index.html` or serve the folder with any static host (GitHub Pages, Netlify, Cloudflare Pages).

To publish on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
